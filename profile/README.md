## The problem we work on

File work gets stitched together out of five different tools: one for subtitles, one for
PDF conversion, one for translation, another for transcription, and a spreadsheet to keep
track of what came out of which. Each one has its own account, its own size limit, and its
own idea of what "done" means.

ForgeFile replaces that stack. Upload a file, say what should happen to it, get the result
back in the format you actually need — with layout, tables and timecodes intact.

## Transcription — structure, not a wall of text

Every transcript comes back with speaker labels and a timecode on every word. Click a word,
the player jumps there. Edit in the browser and each save becomes a new version — the
original is never overwritten. Export as **TXT, SRT, VTT, DOCX or JSON** (text + segments +
speakers + timecodes).

Also in the box: filler-word removal, translated subtitles with timecodes preserved, chapters
and action items, semantic search inside a transcript, and PII redaction that masks names,
emails, phone and card numbers before anything is stored.

## How a job runs

1. **Upload** — or paste a link. Transcription also imports straight from a podcast RSS feed.
2. **See the cost first.** Every job shows what it will consume before it starts. Nothing runs on a number you have not seen.
3. **Watch it work.** A live progress bar with the actual stage — queued, processing, finalizing — and an ETA, not a spinner.
4. **Change your mind → full refund.** Cancel mid-job and the credits come back.
5. **Get notified.** In-app, email or push when it finishes or fails.

There is a free tier with no card required, so you can put real files through it before
deciding anything. [See the plans](https://forgefile.com/pricing).

Everything the web app does is available over a REST API with webhook callbacks, so

names, emails, phone numbers, card numbers, document numbers and other identifiers are
